# Mini Marketplace – working notes

Event-driven marketplace: Go microservices behind a gin API gateway, a Next.js frontend, Postgres/Redis/Kafka,
deployed with Docker Swarm + Traefik. Full documentation lives in [`.claude/docs/`](.claude/docs/README.md).

## Layout
```
apps/frontend/        Next.js 14 UI (talks only to the gateway)
services/api-gateway/ REST (gin) → gRPC; JWT auth, RBAC, rate limiting, ownership checks
services/auth-service/    accounts, passwords, JWT issue/refresh      gRPC :50051
services/order-service/   orders, order outbox, status state machine  gRPC :50052
services/product-service/ catalog, inventory reserve/release          gRPC :50053
services/user-service/    buyer/seller profiles                       gRPC :50054
deploy/               infra.yml (postgres, redis, kafka), services.yml (traefik + apps), traefik/, .env.example
scripts/              gen-dev-certs.sh, build-images.sh
.github/workflows/    CI
```
Each service is its own Go module (`go.mod`), built from its own directory (`docker build services/<name>`).
`.pb.go` files are generated by `buf generate` (`services/<svc>/buf.gen.yaml`) and copied into the consumers; do not edit them.

## Commands
```bash
# build / vet / test one service (from services/<name>)
go build ./... && go vet ./... && go test ./...
# tests that need Postgres are skipped unless this is set (a throw-away DB is created per test)
export TEST_POSTGRES_DSN="host=localhost port=5432 user=postgres password=postgres sslmode=disable"

# local infra + all services (needs deploy/.env; see deploy/.env.example)
cp deploy/.env.example deploy/.env && ./scripts/gen-dev-certs.sh && ./scripts/build-images.sh
docker swarm init
./scripts/deploy.sh            # infra stack "marketplace-infra" then app stack "marketplace"

# frontend
cd apps/frontend && npm install && npm run dev
```

## Conventions
- Never commit `.env`, keys, certs or binaries (`.gitignore` blocks them); add new settings to the matching `.env.example`.
- Identity comes **only** from the JWT (set by the gateway middleware). Never trust user/buyer/seller IDs, prices, totals or statuses from request bodies.
- Service layer returns `status.Error(codes.X, …)`; the gateway maps gRPC codes to HTTP (`handler/helpers.go`).
- Cross-service side effects go through the transactional **outbox** (DB row + worker → Kafka). Consumers must be idempotent.
- Money is `NUMERIC(18,2)` in Postgres, `float64` on the wire, integer cents in arithmetic (`order-service/internal/service/money.go`).
- Add tests with every behavior change (see `.claude/docs/testing.md`).
- Demo data only with `SEED_DEMO_DATA=true` (never in production).
