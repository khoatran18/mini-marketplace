# Mini Marketplace

## Project Overview

Mini Marketplace is a distributed e-commerce platform built with a microservices
architecture. The system supports user authentication, role-based authorization,
product listing, order placement, and sequential inventory processing using Kafka.

The platform is designed to simulate production-grade architecture, featuring
high availability and load balancing across application services, Kafka brokers,
and databases to ensure reliability and scalability.

## Key Features

- Authentication and basic authorization (RBAC)
- Product listing and management
- Order creation and purchase flow
- Sequential inventory processing via Kafka
- Event-driven communication between services
- High availability deployment
- Load balancing for microservices
- Replicated Kafka cluster
- Highly available database setup

## Purpose

This project demonstrates how to design and operate a resilient microservices
system with event-driven patterns and production-like infrastructure.
