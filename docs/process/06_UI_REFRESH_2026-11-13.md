# Làm mới giao diện (2026-11-13)

Quyết định kỹ thuật: ADR-41 (`docs/decisions/01_ADR_LOG.md`). Phiên này chỉ đụng frontend (`apps/frontend`) và 5 truy vấn allowlist của ops-service. Không gọi LLM, không commit.

## Đã làm
- **Khung:** `AppShell` + `PageFrame` thay `ConsoleLayout`; console rộng toàn màn hình, một nút theme; trang bán hàng `max-w-7xl` có `NavBar` dính và nền quầng sáng.
- **Màu:** token mới trong `app/globals.css` (sáng và tối), thẻ nhẹ hơn.
- **Bản đồ hệ thống:** `components/system/*`, `lib/topology.ts`, `lib/useSystemMap.ts`, `lib/systemMapModel.ts`. Dữ liệu: `/admin/system/health` + truy vấn Prometheus qua ops-service + sự cố mở.
- **Chat AI (UI):** `components/ai/*`, `lib/ai-chat.ts` (stub "Tính năng sẽ hoàn thiện sớm…"), `lib/features.ts`.
- **`dev`:** `Role`/`jwt.ts`/chuyển hướng/menu theo role.
- **Đăng nhập, đăng ký, trang chủ:** bố cục mới (`AuthShell`, `RolePicker`, `PasswordInput`).
- **ops-service:** 5 truy vấn mới (`go test ./internal/queries ./internal/api` đạt).

## Cách xem thử khung chat khi cờ gateway còn tắt
Build/chạy frontend với `NEXT_PUBLIC_AI_UI_PREVIEW=true`. Khi gateway bật `FEATURE_AI_CHAT/OPS` và có `AI_SERVICE_URL`, nút tự hiện, không cần biến này.

## Triển khai lại (không cần `deploy.sh` toàn bộ)
Tag `:latest` không đổi nên Swarm không tự kéo bản mới: build rồi ép update.
```bash
# chỉ frontend
./scripts/build-images.sh frontend && docker service update --force marketplace_frontend
# thêm ops-service (5 truy vấn mới cho bản đồ: replica, tần suất, p95)
./scripts/build-images.sh ops-service frontend && docker service update --force marketplace_ops-service && docker service update --force marketplace_frontend
```
- Chỉ khởi động lại (không lấy code mới): `docker service update --force marketplace_frontend`.
- URL API được nướng vào image lúc build (`PUBLIC_HOST` trong `deploy/.env`).
- Thiếu replica/tần suất trên bản đồ = ops-service còn chạy image cũ, hoặc Prometheus không trả lời (trang hiện cảnh báo vàng).
- `NEXT_PUBLIC_AI_UI_PREVIEW=true` chỉ có tác dụng khi **build** (biến `NEXT_PUBLIC_*` được nướng vào bundle); `frontend/Dockerfile` chưa có `ARG` cho biến này, nên với image Swarm hãy bật cờ thật ở gateway (`FEATURE_AI_CHAT/OPS` + `AI_SERVICE_URL`) hoặc thêm `ARG`/`ENV` vào Dockerfile. Chạy `npm run dev` thì dùng được ngay.

## Lỗi bắt được trong lúc làm
1. `GET /config/features` trả `{features:{...}}` (lồng), frontend đọc phẳng: nút chat sẽ không bao giờ hiện. Gateway giả của tôi viết sai theo nên không bắt được; phát hiện khi đối chiếu `handler/ai.go`. Đã sửa `getFeatureFlagsRequest`. **Bài học:** gateway giả phải sao đúng cấu trúc thật; nên có test hợp đồng.
2. Nhãn cạnh chồng lên nhau (tất cả cạnh gateway→service cùng điểm giữa): bỏ nhãn trên cạnh, đưa tần suất vào dòng phụ của node.
3. MiniMap và nút zoom của React Flow trắng ở chế độ tối: bỏ MiniMap (17 node không cần), ghi đè CSS nút điều khiển theo token.
4. Cột trái trang Hệ thống bị kéo giãn khi panel dài: `content-start`.

## Cập nhật sau phản hồi (2026-11-13, chiều)

- **Đăng nhập không chọn vai trò.** Tên đăng nhập duy nhất toàn hệ thống, vai trò gắn với tài khoản từ lúc đăng ký (không đổi được; muốn đổi thì tạo tài khoản mới). `auth-service`: `Login` tra theo username (trường `role` trong request giờ tùy chọn, nếu gửi thì phải khớp), `Register` từ chối username đã dùng ở bất kỳ vai trò nào, migration `00003_accounts_username_unique.sql` tạo index duy nhất theo `username` (bỏ qua kèm NOTICE nếu DB cũ đã có username trùng giữa các vai trò). Cần build lại và cập nhật `auth-service`, `api-gateway`, `frontend`.
- **Khung chat AI luôn hiện** khi đã đăng nhập (`AI_BACKEND_READY = false` trong `lib/ai-chat.ts`); khi nối backend thật, đổi thành `true` để quay lại điều kiện theo cờ `/config/features`.
- **Icon:** dùng `lucide-react`; tiêu đề trang có icon (`components/layout/PageTitle.tsx`); nút giao diện sáng/tối dùng icon Sun/Monitor/Moon.
- **Bản đồ:** đường Kafka vẽ một lần cho mỗi cặp service↔kafka, có mũi tên hai đầu, đi từ cạnh trái kafka sang cạnh phải service (trước đây vòng ngược nhìn như đường thẳng sai).
- **Trang chủ/đăng nhập:** rút gọn lời giới thiệu và chiều cao hero để thấy danh mục ngay; nút "Tạo tài khoản" ẩn khi đã đăng nhập.
- **Không thấy replica/tần suất trên bản đồ:** nguyên nhân là `OPS_API_TOKEN` rỗng ở `deploy/.env` nên gateway trả 503 cho `/admin/ops/*` (log ops-service: "OPS_API_TOKEN chưa đặt"). Đặt token rồi cập nhật `api-gateway` và `ops-service` (xem runbook).
- **Màu chủ đạo đổi từ tím sang xanh ngọc (teal)** (2026-11-13): biến `--brand*`, `--bg`, `--surface-2`, `--line` trong `apps/frontend/app/globals.css`; gradient hero và khung đăng nhập dùng `teal-700 → emerald-800`. Nút chính dùng `teal-700` (tương phản chữ trắng ≥ 5:1).
- **Lỗi đăng nhập "Value must be in list [...]":** `LoginRequest.role` trong `auth.proto` bắt buộc thuộc danh sách; đã thêm `ignore = IGNORE_IF_ZERO_VALUE` và sinh lại `.pb.go` (auth, gateway, order, product, user). Test: `auth-service/internal/server/login_validate_test.go`.
- **Chỉnh tông màu (2026-11-13):** sáng: nền xám xanh đậm hơn, viền và chữ phụ đậm hơn, card có bóng nhẹ; tối: bỏ nền xanh đen, dùng xám than trung tính, màu nhấn teal dịu (`94 200 188`), giảm quầng sáng. Bản đồ tự fit lại khi đổi kích thước (sidebar, panel) — trước đó bị cắt mép phải.
- **Thanh trên ở light mode:** dải teal đậm (`.bar` trong `globals.css`, tái định nghĩa token bên trong để chữ/nút tự đổi màu), mục menu đang chọn là nền teal đặc chữ trắng. Dark mode giữ thanh theo bề mặt.
- **Quản lý tài khoản (admin):** trang `/admin/accounts` (menu "Tài khoản", chỉ admin): lọc theo role, tìm username, tạo admin/dev, xoá, đặt lại mật khẩu. Backend: gRPC `ListAccounts/CreateStaffAccount/DeleteStaffAccount/ResetStaffPassword` ở auth-service; luật bảo vệ nằm ở service (không tự xoá, không xoá admin cuối, chỉ admin/dev). Test: `TestStaffAccountManagement`.
- **Đăng ký:** chỉ còn Người mua / Người bán (nhân viên do chủ cửa hàng tạo; dev/admin do admin tạo), bỏ mô tả dài, thêm ô nhập lại mật khẩu kiểm tra ngay khi gõ.
- **Danh mục:** dòng danh mục chính có nền nhạt, chữ đậm màu nhấn, icon thư mục và nhãn "Danh mục chính"; danh mục con thụt vào kèm icon mũi tên.
